# 로또

## 프로그램 동작

1. `구입금액을 입력해 주세요.` 문구 출력
2. 구입 금액 입력
3. `n개를 구매했습니다.` 문구 출력 (구입 개수 = n개)
4. n개의 **중복되지 않는** 6개의 로또 번호 출력
5. `당첨 번호를 입력해 주세요.` 문구 출력
6. **중복되지 않는** 당첨 번호 6개 입력 (`,`로 구분)
7. `보너스 번호를 입력해 주세요.` 문구 출력
8. 보너스 번호 1개 입력
9. 당첨 번호로 발급된 로또 등수 계산
10. `당첨 통계` 문구 출력 
11. 5등부터 1등까지 당첨 금액과 당첨된 로또 개수 출력
12. `총 수익률은 00.0%입니다.` 문구 출력

### 로또 당첨 조건

#### 1등
```
6개 번호 일치
당첨금 : 2,000,000,000원
```

#### 2등
```
5개 번호 + 보너스 번호 일치
당첨금 : 30,000,000원
```

#### 3등
```
5개 번호 일치
당첨금 : 1,500,000원
```

#### 4등
```
4개 번호 일치
당첨금 : 50,000원
```

#### 5등
```
3개 번호 일치
당첨금 : 5,000원
```

## 기능 목록

- [x] 로또 구입 금액 입력
- [x] 로또 발행
- [x] 당첨 번호 입력
- [x] 보너스 번호 입력
- [ ] 당첨 내역 출력
- [ ] 수익률 출력

## 예외 처리

```text
사용자가 잘못된 값을 입력할 경우 IllegalArgumentException 발생
예외 상황 시 [ERROR]로 시작하는 에러 문구 출력
예외가 발생한 부분부터 입력을 다시 받음
```

- [x] 입력 값이 숫자가 아닌 경우 
  - [x] 로또 구입 금액
  - [x] 당첨 번호
  - [x] 보너스 번호
- [x] 로또 구입 금액이 로또 금액 이하인 경우
- [x] 로또 구입 금액이 로또 금액으로 나누어 떨어지지 않는 경우
- [x] 당첨 번호가 중복되는 경우
- [x] 당첨 번호의 개수가 6개가 아닌 경우
- [x] 당첨 번호가 1 ~ 45 범위 이외인 경우
- [x] 보너스 번호가 당첨 번호랑 같은 경우
- [x] 보너스 번호가 1 ~ 45 범위 이외인 경우

### 프로그래밍 요구사항

- indent(인덴트, 들여쓰기) depth 2까지 허용
- 3항 연산자 쓰지 않기
- 함수 (또는 메서드)가 한 가지 일만 하도록 최대한 적게
- 함수 (또는 메서드) 길이가 15라인을 넘어가지 않도록 구현
- else 예약어 쓰지 않기
  - switch/case도 허용하지 않음
- Enum을 적용하여 구현
- 구현한 기능에 대한 단위 테스트 작성
